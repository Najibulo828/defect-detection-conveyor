Конвейер с ИИ для обнаружения дефектов

1. Описание проекта

Цель проекта — разработать прототип конвейера, который автоматически обнаруживает дефекты изделий с помощью искусственного интеллекта и сортирует продукцию на годную и бракованную.

2. Выбранный эталон

В качестве основы для разработки выбрана платформа Ultralytics YOLO — семейство моделей искусственного интеллекта для обнаружения объектов на изображениях.

Репозиторий оригинального решения: https://github.com/ultralytics/ultralytics

Официальная документация: https://docs.ultralytics.com/

3. Почему выбрано это решение

* Возможность обучать модель на собственных изображениях изделий.
* Обнаружение объектов и визуальных дефектов.
* Поддержка языка программирования Python.
* Возможность обработки изображений в реальном времени при подходящем оборудовании.
* Возможность интеграции с программой управления конвейером.

4. Предполагаемая архитектура

1. Конвейер перемещает изделия.
2. Камера получает изображения.
3. Модель YOLO анализирует изображения и обнаруживает дефекты.
4. Программа передаёт результат проверки контроллеру.
5. Контроллер управляет механизмом сортировки изделий.

5. Планируемые технологии

* Python — основной язык программирования.
* Ultralytics YOLO — модель искусственного интеллекта.
* Arduino — управление датчиками и механизмом отбраковки.
* Git и GitHub — хранение исходного кода и документации.

6. Статус проекта

Начальный этап: выбор эталонного решения и проектирование архитектуры прототипа.
